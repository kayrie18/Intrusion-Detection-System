How it was built

1. Install

Npcap 1.90 (packet capture driver) and then the Suricata 8.0.8 Windows installer. Check with .\suricata.exe --build-info.

2. Configure

I found my Wi-Fi IP with ipconfig. The default HOME_NET already covers private address ranges. The community rule files were not installed, so I load only my custom rules with -S rules\local.rules.

3. Custom rules

SIDDetectsHow
1000001PingICMP echo request
1000002SYN port scan20 SYN packets from one source in 10 s
1000003SSH brute force5 SYN packets to port 22 in 60 s
1000004Scanner toolHTTP user-agent contains sqlmap

4. Run

.\suricata.exe -T -c suricata.yaml -S rules\local.rules -v
.\suricata.exe -c suricata.yaml -S rules\local.rules -i 192.168.214.55

The config test reported 6 rules loaded and 0 failed, and the engine started.

Problems and fixes

  • WSL would not install (error REGDB_E_CLASSNOTREG, even after repair), so I switched to Suricata on Windows.
  • Npcap install aborted with access denied (80070005). My antivirus blocked the driver. I paused it, installed, and turned it back on.
  • Two rules failed to parse. Suricata 8 needs count 20, seconds 10 with spaces, not colons.

The full guide, rules and scripts are in the GitHub repository.
